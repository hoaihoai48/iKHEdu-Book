## Navigation rules

README phải liên kết được tới file tồn tại thực tế. Không đưa nội dung dài vào README nếu nội dung đó đã có trong file canonical. Mọi thay đổi tên file, thứ tự học hoặc trạng thái phải cập nhật README và ghi vào `decision-log.md`.

Nếu một buổi học có cả `.docx` và `.md`, ghi rõ file canonical và file export/legacy; không để người học phải đoán bản nào là bản hiện hành.
