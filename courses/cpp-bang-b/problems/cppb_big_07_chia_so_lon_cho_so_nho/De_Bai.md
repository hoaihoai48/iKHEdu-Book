# Chia Số Lớn Cho Số Nhỏ (Lấy Thương)

**Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho số nguyên lớn $A$ và số nguyên nhỏ $b$ ($1 \le b \le 10^9$). Hãy tìm phần thương nguyên của phép chia $A / b$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Số nguyên dương $b$ ($1 \le b \le 10^9$).

## Output
- In ra phần thương nguyên của phép chia $A / b$.

## Sample 1
### Input
```text
1000
8
```
### Output
```text
125
```
### Giải thích
1000 / 8 = 125.

## Ràng buộc
- $100\%$ số test có $|A| \le 10^5, b \le 10^9$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
