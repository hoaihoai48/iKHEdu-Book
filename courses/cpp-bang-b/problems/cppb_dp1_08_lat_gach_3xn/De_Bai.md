# Lát Gạch Bảng 3xN

## Bối cảnh
Cần lát kín một bảng kích thước $3 \times N$ bằng các viên gạch domino $2 \times 1$.

## Nhiệm vụ
Tính số cách lát kín bảng modulo $10^9+7$. Nếu không thể lát kín in 0.

## Input
- Một dòng chứa số nguyên dương $N$ ($1 \le N \le 10^5$).

## Output
- Số cách lát theo modulo $10^9 + 7$.

## Sample 1
### Input
```text
2
```
### Output
```text
3
```

## Ràng buộc
- $100\%$ số test có $1 \le N \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
