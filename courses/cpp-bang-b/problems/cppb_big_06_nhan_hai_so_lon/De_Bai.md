# Nhân Hai Số Nguyên Lớn

**Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho 2 số nguyên lớn $A$ và $B$. Hãy tính tích $A \times B$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 2000$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 2000$).

## Output
- In ra một chuỗi là tích $A \times B$.

## Sample 1
### Input
```text
123
45
```
### Output
```text
5535
```
### Giải thích
123 * 45 = 5535.

## Ràng buộc
- $100\%$ số test có $|A|, |B| \le 2000$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
