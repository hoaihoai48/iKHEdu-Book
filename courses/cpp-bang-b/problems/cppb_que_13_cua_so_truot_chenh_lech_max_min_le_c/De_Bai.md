# Đoạn Con Dài Nhất Có Độ Chênh Lệch Max-Min <= C

## Bối cảnh
Tìm độ dài lớn nhất của một đoạn con liên tiếp sao cho chênh lệch giữa phần tử lớn nhất và nhỏ nhất trong đoạn $\le C$.

## Nhiệm vụ
In ra độ dài lớn nhất.

## Input
- Dòng 1: Hai số $N$ và $C$ ($1 \le N \le 10^5, 0 \le C \le 10^9$).
- Dòng 2: $N$ số nguyên $A_1, A_2, \dots, A_N$ ($1 \le A_i \le 10^9$).

## Output
- Độ dài lớn nhất.

## Sample 1
### Input
```text
6 2
4 2 2 2 4 4
```
### Output
```text
6
```

## Ràng buộc
- $100\%$ số test có $1 \le N \le 10^5, 0 \le C, A_i \le 10^9$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
