# Bậc Thang Cơ Bản

## Bối cảnh
Một cầu thang có $N$ bậc. Mỗi bước bạn có thể bước lên $1$ bậc hoặc $2$ bậc.

## Nhiệm vụ
Hãy tính số cách khác nhau để leo lên đến đỉnh bậc thứ $N$, lấy dư cho $10^9 + 7$.

## Input
- Một dòng duy nhất chứa số nguyên dương $N$ ($1 \le N \le 10^5$).

## Output
- In ra số cách leo lên bậc $N$ theo modulo $10^9 + 7$.

## Sample 1
### Input
```text
3
```
### Output
```text
3
```

## Ràng buộc
- $100\%$ số test có $1 \le N \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
