# Chia Hai Số Nguyên Lớn (A / B)

**Phân loại bài toán:** `Advanced Challenge` (Thử thách mở rộng)
## Bối cảnh
Cho 2 số nguyên dương lớn $A$ và $B$. Hãy tìm thương nguyên $\lfloor A / B \rfloor$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 1000$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 1000$).

## Output
- In ra thương nguyên $\lfloor A / B \rfloor$.

## Sample 1
### Input
```text
1000
30
```
### Output
```text
33
```
### Giải thích
1000 / 30 = 33.

## Ràng buộc
- $100\%$ số test có $|A|, |B| \le 1000$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
