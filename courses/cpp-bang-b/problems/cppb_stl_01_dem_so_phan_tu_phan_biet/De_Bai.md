# Đếm Số Phần Tử Phân Biệt

## Bối cảnh
Cho mảng $A$ gồm $N$ số nguyên. Cần đếm xem trong mảng có bao nhiêu giá trị phân biệt.

## Nhiệm vụ
In ra số lượng phần tử phân biệt.

## Input
- Dòng 1: Số nguyên $N$ ($1 \le N \le 10^5$).
- Dòng 2: $N$ số nguyên $A_1, A_2, \dots, A_N$ ($1 \le A_i \le 10^9$).

## Output
- Số phần tử phân biệt.

## Sample 1
### Input
```text
5
2 3 2 2 3
```
### Output
```text
2
```

## Ràng buộc
- $100\%$ số test có $1 \le N \le 10^5, 1 \le A_i \le 10^9$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
