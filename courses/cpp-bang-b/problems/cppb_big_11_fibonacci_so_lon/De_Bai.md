# Số Fibonacci Lớn Thứ N

> [!NOTE]
> **Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho số nguyên $N$. Hãy in ra giá trị chính xác của số Fibonacci thứ $N$ ($F_0 = 0, F_1 = 1, F_2 = 1, \dots$).

## Input
- Một dòng duy nhất chứa số nguyên $N$ ($0 \le N \le 1000$).

## Output
- In ra giá trị chính xác của $F_N$.

## Sample 1
### Input
```text
10
```
### Output
```text
55
```
### Giải thích
F(10) = 55.

## Ràng buộc
- $100\%$ số test có $N \le 1000$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
