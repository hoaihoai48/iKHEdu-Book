# Hứng Nước Mưa (Trapping Rain Water)

## Bối cảnh
Cho bản đồ độ cao gồm $N$ cột có chiều rộng 1. Sau cơn mưa, nước sẽ bị đọng lại giữa các cột.

## Nhiệm vụ
Tính tổng thể tích nước mưa đọng lại.

## Input
- Dòng 1: Số nguyên $N$ ($1 \le N \le 10^5$).
- Dòng 2: $N$ số nguyên không âm $H_1, H_2, \dots, H_N$ ($0 \le H_i \le 10^5$).

## Output
- Tổng lượng nước mưa đọng lại.

## Sample 1
### Input
```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```
### Output
```text
6
```

## Ràng buộc
- $100\%$ số test có $1 \le N \le 10^5, 0 \le H_i \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
