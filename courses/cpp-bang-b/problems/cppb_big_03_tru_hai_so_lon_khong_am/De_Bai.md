# Trừ Hai Số Nguyên Lớn (A >= B)

> [!NOTE]
> **Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho 2 số nguyên dương lớn $A$ và $B$ ($A \ge B$). Hãy tính hiệu $A - B$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 10^5, B \le A$).

## Output
- In ra hiệu $A - B$.

## Sample 1
### Input
```text
1000
999
```
### Output
```text
1
```
### Giải thích
1000 - 999 = 1.

## Ràng buộc
- $100\%$ số test có $A \ge B, |A| \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
