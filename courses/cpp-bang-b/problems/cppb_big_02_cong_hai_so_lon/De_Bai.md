# Cộng Hai Số Nguyên Lớn

**Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho 2 số nguyên dương lớn $A$ và $B$. Hãy tính tổng $A + B$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 10^5$).

## Output
- In ra một chuỗi là tổng $A + B$.

## Sample 1
### Input
```text
9876
543
```
### Output
```text
10419
```
### Giải thích
9876 + 543 = 10419.

## Ràng buộc
- $100\%$ số test có $|A|, |B| \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
