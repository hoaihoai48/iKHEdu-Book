# Trừ Hai Số Lớn Tổng Quát (Có Thể Âm)

> [!NOTE]
> **Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho 2 số nguyên dương lớn $A$ và $B$. Hãy tính hiệu $A - B$ (nếu âm thì in dấu trừ ở đầu).

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 10^5$).

## Output
- In ra giá trị $A - B$.

## Sample 1
### Input
```text
543
9876
```
### Output
```text
-9333
```
### Giải thích
543 - 9876 = -9333.

## Ràng buộc
- $100\%$ số test có $|A|, |B| \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
