# Nhân Số Lớn Với Số Nhỏ

## Bối cảnh
Một phòng thí nghiệm thiên văn học đo đạc chu kỳ quay của một chuẩn tinh với số lượng xung năng lượng là số nguyên lớn A, và mỗi xung kéo dài b nano giây (b <= 10^9). Hãy tính tổng thời gian chính xác A * b.

## Nhiệm vụ
Cho số nguyên lớn A và số nguyên nhỏ b (0 <= b <= 10^9). Hãy tính tích A * b.

## Input
- Dòng 1: Chuỗi số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Số nguyên $b$ ($0 \le b \le 10^9$).

## Output
- In ra giá trị của $A \times b$.

## Sample 1
### Input
```text
123456789
5
```
### Output
```text
617283945
```
### Giải thích
123456789 * 5 = 617283945.

## Ràng buộc
- $100\%$ số test có $|A| \le 10^5, 0 \le b \le 10^9$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}.
