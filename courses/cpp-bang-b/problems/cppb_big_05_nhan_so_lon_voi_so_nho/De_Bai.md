# Nhân Số Lớn Với Số Nhỏ

> [!NOTE]
> **Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho số nguyên lớn $A$ và số nguyên nhỏ $b$ ($0 \le b \le 10^9$). Hãy tính tích $A \times b$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Số nguyên $b$ ($0 \le b \le 10^9$).

## Output
- In ra tích $A \times b$.

## Sample 1
### Input
```text
48
7
```
### Output
```text
336
```
### Giải thích
48 * 7 = 336.

## Ràng buộc
- $100\%$ số test có $|A| \le 10^5, b \le 10^9$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
