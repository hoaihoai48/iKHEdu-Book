# So Sánh Hai Số Nguyên Lớn

**Phân loại bài toán:** `Core Foundation` (Bắt buộc)
## Bối cảnh
Cho 2 số nguyên dương lớn $A$ và $B$. Hãy so sánh $A$ và $B$.

## Input
- Dòng 1: Chuỗi ký tự số $A$ ($1 \le |A| \le 10^5$).
- Dòng 2: Chuỗi ký tự số $B$ ($1 \le |B| \le 10^5$).

## Output
- In ra `>` nếu $A > B$, `<` nếu $A < B$, `=` nếu $A = B$.

## Sample 1
### Input
```text
123456789
98765432
```
### Output
```text
>
```
### Giải thích
A có 9 chữ số, B có 8 chữ số -> A > B.

## Ràng buộc
- $100\%$ số test có $|A|, |B| \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
