# Cặp Điểm Gần Nhất (Closest Pair Of Points)

## Bối cảnh
Cho $N$ điểm trên mặt phẳng 2D. Tìm bình phương khoảng cách Euclid nhỏ nhất giữa hai điểm bất kỳ.

## Nhiệm vụ
In ra bình phương khoảng cách nhỏ nhất.

## Input
- Dòng 1: Số nguyên $N$ ($2 \le N \le 10000$).
- $N$ dòng tiếp theo: Mỗi dòng gồm tọa độ $X_i, Y_i$ ($0 \le X_i, Y_i \le 10^5$).

## Output
- Bình phương khoảng cách nhỏ nhất.

## Sample 1
### Input
```text
4
0 0
1 2
3 1
4 0
```
### Output
```text
5
```

## Ràng buộc
- $100\%$ số test có $2 \le N \le 10000, 0 \le X_i, Y_i \le 10^5$.
- Thời gian: $1.0\text{s}$, Bộ nhớ: $256\text{MB}$.
