# Tổng chữ số của số 3 chữ số


## Bối cảnh

Trong bài kiểm tra, người dùng cần tính nhanh tổng một dãy số. Hãy viết chương trình hỗ trợ tính toán.

## Nhiệm vụ

Nhập một số nguyên dương $N$ có đúng 3 chữ số. Hãy tính tổng của 3 chữ số đó.
## Input

Một số tự nhiên $N$ ($100 \le N \le 999$).
## Output

Tổng 3 chữ số.
## Sample 1

### Input
```text
358
```
### Output
```text
16
```
### Giải thích

$3 + 5 + 8 = 16$.
