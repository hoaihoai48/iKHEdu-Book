# Tổng bình phương


## Bối cảnh

Nhà toán học muốn tính tổng bình phương của các số từ 1 đến $N$: $1^2 + 2^2 + 3^2 + \dots + N^2$. Hãy viết chương trình tính.

## Nhiệm vụ

Nhập vào số nguyên dương $N$. Hãy tính tổng:
 $$S = 1^2 + 2^2 + 3^2 + \dots + N^2$$
## Input

Một số tự nhiên $N$ ($1 \le N \le 1000$).
## Output

Một số nguyên duy nhất là tổng $S$.
## Sample 1

### Input
```text
3
```
### Output
```text
14
```
### Giải thích

$1^2 + 2^2 + 3^2 = 1 + 4 + 9 = 14$.
