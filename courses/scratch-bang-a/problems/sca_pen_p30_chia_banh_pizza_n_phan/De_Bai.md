# Chia Bánh Pizza N Miếng Đa Sắc

## Bối cảnh

Bữa tiệc sinh nhật có chiếc bánh pizza tròn cần chia đều cho N bạn nhỏ, mỗi miếng một vị và màu sắc khác nhau.

## Nhiệm vụ

Vẽ đường tròn và các nan quạt từ tâm ra đường viền, chia góc 360 / N độ.

## Input

Nhập số phần N (ví dụ N = 6 hoặc 8).

## Output

Chiếc bánh tròn được chia thành N nan quạt màu sắc rực rỡ.

## Sample 1

### Input
```text
Sự kiện: Nhập số phần N (ví dụ N = 6 hoặc 8).
```

### Output
```text
Kết quả: Chiếc bánh tròn được chia thành N nan quạt màu sắc rực rỡ.
```

### Giải thích

Mỗi nan quạt đi từ tâm ra bán kính R, xoay góc, đi về tâm.
