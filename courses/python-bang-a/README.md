## 4. Quy chuẩn Lesson Package

Mỗi bài học (`lessons/lesson-XX/`) gồm **2 file bắt buộc**:
1. **`LessonXX_Production_Content.md`**: Nội dung bài học học thuật chuyên sâu (khái niệm máy tính, cú pháp, bảng dry run biến thiên ô nhớ, tử huyệt bẫy lỗi, sơ đồ SVG và ngân hàng Concept Quiz có đáp án chi tiết).
2. **`Bai_Tap.md`**: Hệ thống bài tập thực hành phân tầng (từ cơ bản P0 đến thử thách P3/P4), bám sát ma trận năng lực và mã bài toán.
