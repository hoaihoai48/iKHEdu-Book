# Đếm Số Lượng Chữ Số Của N


## Nhiệm vụ

Nhập vào một số nguyên dương $N$. Dùng vòng lặp `while` và phép chia nguyên `// 10`, hãy đếm xem số $N$ có bao nhiêu chữ số.
## Input

Một số tự nhiên $N$ ($1 \le N \le 10^{18}$).
## Output

Số lượng chữ số của $N$.
## Sample 1

### Input
```text
2026
```
### Output
```text
4
```
## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
