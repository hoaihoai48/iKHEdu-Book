# Tổng Tích Hai Số Liền Nhau


## Nhiệm vụ

Cho số nguyên dương $N$. Hãy tính tổng:
  $$S = 1 \times 2 + 2 \times 3 + 3 \times 4 + \dots + N \times (N + 1)$$
## Input

Một số nguyên dương $N$ ($1 \le N \le 10^5$).
## Output

Tổng $S$.
## Sample 1

### Input
```text
3
```
### Output
```text
20
```
### Giải thích

$1 \times 2 + 2 \times 3 + 3 \times 4 = 2 + 6 + 12 = 20$.
