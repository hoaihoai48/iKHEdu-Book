# Dãy Số Nhân Đôi


## Nhiệm vụ

Nhập số nguyên $N$ ($1 \le N \le 30$). Hãy in ra $N$ số đầu tiên của dãy số nhân đôi: $1, 2, 4, 8, 16, 32, \dots$ trên cùng một dòng.
## Input

Một số nguyên $N$.
## Output

Dãy $N$ số, cách nhau bởi dấu cách.
## Sample 1

### Input
```text
5
```
### Output
```text
1 2 4 8 16
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
