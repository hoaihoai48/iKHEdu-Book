# Đếm Ngược Phóng Tên Lửa


## Nhiệm vụ

Trước khi phóng tàu vũ trụ, đồng hồ đếm ngược từ $N$ về 1, cuối cùng in ra chữ `PHONG!`.
## Input

Một số tự nhiên $N$ ($1 \le N \le 20$).
## Output

Mỗi số trên một dòng, dòng cuối in `PHONG!`.
## Sample 1

### Input
```text
3
```
### Output
```text
3
2
1
PHONG!
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
