# In Từng Chữ Cái Xuống Dòng


## Nhiệm vụ

Nhập vào một từ $S$. Hãy in ra từng chữ cái của từ đó, mỗi chữ cái nằm trên một dòng riêng biệt.
## Input

Một chuỗi ký tự $S$ ($1 \le |S| \le 100$).
## Output

Mỗi ký tự trên một dòng.
## Sample 1

### Input
```text
CAT
```
### Output
```text
C
A
T
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
