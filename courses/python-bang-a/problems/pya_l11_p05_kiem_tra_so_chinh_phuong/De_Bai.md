# Kiểm Tra Số Chính Phương


## Bối cảnh

Số chính phương là số bằng bình phương của một số tự nhiên (ví dụ: $0, 1, 4, 9, 16, 25, \dots$).
## Nhiệm vụ

Nhập số nguyên dương $N$. Kiểm tra $N$ có phải số chính phương không. Nếu đúng in `YES`, ngược lại in `NO`.
## Input

Một số nguyên $N$ ($1 \le N \le 10^9$).
## Output

`YES` hoặc `NO`.
## Sample 1

### Input
```text
25
```
### Output
```text
YES
```
## Sample 2

### Input
```text
20
```
### Output
```text
NO
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
