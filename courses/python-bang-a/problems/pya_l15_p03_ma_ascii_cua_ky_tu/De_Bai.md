# Mã ASCII Của Ký Tự


## Nhiệm vụ

Nhập một ký tự bất kỳ từ bàn phím. Hãy in ra mã số ASCII của ký tự đó.
## Input

Một ký tự duy nhất $C$.
## Output

Một số nguyên là mã ASCII.
## Sample 1

### Input
```text
A
```
### Output
```text
65
```
## Sample 2

### Input
```text
a
```
### Output
```text
97
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
