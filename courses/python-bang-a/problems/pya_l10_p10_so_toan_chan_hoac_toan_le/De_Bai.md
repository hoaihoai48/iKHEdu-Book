# Số Toàn Chẵn Hoặc Toàn Lẻ


## Bối cảnh

Số "Toàn chẵn" là số mà mọi chữ số của nó đều là số chẵn. Số "Toàn lẻ" là số mà mọi chữ số của nó đều là số lẻ.
## Nhiệm vụ

Nhập số nguyên dương $N$. In ra `TOAN CHAN` nếu $N$ là số toàn chẵn, in `TOAN LE` nếu $N$ toàn lẻ, ngược lại in `BINH THUONG`.
## Input

Một số tự nhiên $N$ ($1 \le N \le 10^{15}$).
## Output

`TOAN CHAN`, `TOAN LE` hoặc `BINH THUONG`.
## Sample 1

### Input
```text
2468
```
### Output
```text
TOAN CHAN
```
## Sample 2

### Input
```text
1395
```
### Output
```text
TOAN LE
```
## Sample 3

### Input
```text
2418
```
### Output
```text
BINH THUONG
```
