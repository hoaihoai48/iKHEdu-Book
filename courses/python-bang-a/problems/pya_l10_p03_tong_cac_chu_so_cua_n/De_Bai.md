# Tổng các chữ số của N


## Bối cảnh

Trong bài kiểm tra, người dùng cần tính nhanh tổng một dãy số. Hãy viết chương trình hỗ trợ tính toán.

## Nhiệm vụ

Cho một số tự nhiên $N$ bất kỳ. Hãy tính tổng tất cả các chữ số cấu tạo nên số $N$.
## Input

Một số nguyên $N$ ($0 \le N \le 10^{18}$).
## Output

Tổng các chữ số của $N$.
## Sample 1

### Input
```text
2024
```
### Output
```text
8
```
### Giải thích

$2 + 0 + 2 + 4 = 8$.
## Sample 2

### Input
```text
0
```
### Output
```text
0
```
### Giải thích

Chữ số 0 có tổng bằng 0.


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
