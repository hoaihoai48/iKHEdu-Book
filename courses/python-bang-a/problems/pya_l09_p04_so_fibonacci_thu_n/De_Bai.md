# Số Fibonacci Thứ N


## Nhiệm vụ

Dãy Fibonacci được định nghĩa: $F_1 = 1, F_2 = 1, F_n = F_{n-1} + F_{n-2}$ với $n \ge 3$. Nhập vào số tự nhiên $N$. Hãy tìm và in ra số Fibonacci thứ $N$.
## Input

Một số tự nhiên $N$ ($1 \le N \le 40$).
## Output

Giá trị $F_N$.
## Sample 1

### Input
```text
6
```
### Output
```text
8
```
### Giải thích

Dãy là 1, 1, 2, 3, 5, 8. Số thứ 6 là 8.
