# Số Siêu Nguyên Tố (Super Prime)


*(Đề thi Tin học trẻ Bảng A)*

## Bối cảnh

Một số tự nhiên được gọi là "Siêu nguyên tố" nếu bản thân nó là số nguyên tố, và khi ta lần lượt xóa bớt chữ số tận cùng bên phải thì các số thu được vẫn luôn là số nguyên tố!
  * Ví dụ: Số $239$ là số nguyên tố.
  * Cắt đuôi 9 còn $23$ (vẫn là số nguyên tố).
  * Cắt đuôi 3 còn $2$ (vẫn là số nguyên tố).
  $\implies 239$ là một Siêu nguyên tố!
## Nhiệm vụ

Cho số tự nhiên $N$. Hãy kiểm tra xem $N$ có phải là Siêu nguyên tố hay không. In `YES` hoặc `NO`.
## Input

Một số tự nhiên $N$ ($1 \le N \le 10^7$).
## Output

`YES` hoặc `NO`.
## Sample 1

### Input
```text
239
```
### Output
```text
YES
```
## Sample 2

### Input
```text
23
```
### Output
```text
YES
```
## Sample 3

### Input
```text
27
```
### Output
```text
NO
```
