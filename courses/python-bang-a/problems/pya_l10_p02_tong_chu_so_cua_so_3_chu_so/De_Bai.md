# Tổng Chữ Số Của Số 3 Chữ Số


## Nhiệm vụ

Nhập một số nguyên dương $N$ có đúng 3 chữ số. Hãy tính tổng của 3 chữ số đó.
## Input

Một số tự nhiên $N$ ($100 \le N \le 999$).
## Output

Tổng 3 chữ số.
## Sample 1

### Input
```text
358
```
### Output
```text
16
```
### Giải thích

$3 + 5 + 8 = 16$.


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
