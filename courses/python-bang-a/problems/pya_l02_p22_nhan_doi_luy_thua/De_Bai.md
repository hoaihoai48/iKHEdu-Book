# Nhân đôi lũy thừa


## Bối cảnh

Trong mô hình sinh trưởng tế bào vi sinh, số lượng cá thể ban đầu là $1$ và nhân đôi sau mỗi chu kỳ thời gian.

## Nhiệm vụ

Cho số nguyên $N$ ($0 \le N \le 30$). Hãy tính số lượng cá thể sau $N$ chu kỳ nhân đôi ($2^N$).

## Input

Một số tự nhiên $n$ ($1 \le n \le 30$).
## Output

In ra số lượng tế bào sau $n$ giờ ($2^n$).
## Sample 1

### Input
```text
4
```
### Output
```text
16
```
### Giải thích

Sau 4 giờ: $2^4 = 16$ tế bào.
