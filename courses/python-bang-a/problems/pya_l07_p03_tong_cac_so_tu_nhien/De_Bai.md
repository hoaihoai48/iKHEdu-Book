# Tổng Các Số Tự Nhiên


## Nhiệm vụ

Nhập số nguyên dương $N$. Hãy tính tổng $S = 1 + 2 + 3 + \dots + N$.
## Input

Một số tự nhiên $N$ ($1 \le N \le 10^5$).
## Output

Một số nguyên duy nhất là tổng $S$.
## Sample 1

### Input
```text
4
```
### Output
```text
10
```
### Giải thích

$1 + 2 + 3 + 4 = 10$.

* **Giới hạn thời gian:** $1.0\text{s}$
