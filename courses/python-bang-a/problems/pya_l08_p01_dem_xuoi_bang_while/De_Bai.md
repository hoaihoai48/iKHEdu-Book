# Đếm Xuôi Bằng While


## Nhiệm vụ

Nhập vào số tự nhiên $N$. Dùng vòng lặp `while`, hãy in ra các số từ $1$ đến $N$ trên một dòng.
## Input

Một số tự nhiên $N$ ($1 \le N \le 100$).
## Output

Dãy số từ 1 đến $N$.
  ```python
  N = int(input())
  i = 1
  while i <= N:
      print(i, end=" ")
      i = i + 1
  ```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
