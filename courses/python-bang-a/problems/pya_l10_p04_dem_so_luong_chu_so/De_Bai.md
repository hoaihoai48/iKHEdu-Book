# Đếm Số Lượng Chữ Số


## Nhiệm vụ

Cho số nguyên không âm $N$. Hãy cho biết số $N$ có bao nhiêu chữ số.
## Input

Một số nguyên $N$ ($0 \le N \le 10^{18}$).
## Output

Số lượng chữ số.
## Sample 1

### Input
```text
123456
```
### Output
```text
6
```
### Giải thích

Có 6 chữ số.
## Sample 2

### Input
```text
0
```
### Output
```text
1
```
### Giải thích

Số 0 có đúng 1 chữ số.
* **Lưu ý:** Chú ý xử lý trường hợp đặc biệt $N = 0$.


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
