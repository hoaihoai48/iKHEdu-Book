# Phân tích ra thừa số nguyên tố


## Bối cảnh

Định lý cơ bản của số học khẳng định mọi số tự nhiên lớn hơn 1 đều phân tích được duy nhất thành tích các thừa số nguyên tố. Phép phân tích này đóng vai trò cốt lõi trong mật mã học.

## Nhiệm vụ

Mọi số tự nhiên $N \ge 2$ đều có thể phân tích thành tích của các thừa số nguyên tố. Cho số tự nhiên $N$. Hãy in ra dạng phân tích của $N$.
## Input

Một số tự nhiên $N$ ($2 \le N \le 10^6$).
## Output

Dãy các thừa số nguyên tố tăng dần theo định dạng `p1 * p2 * ...`.
## Sample 1

### Input
```text
60
```
### Output
```text
2 * 2 * 3 * 5
```
### Giải thích

Với dữ liệu đầu vào là `60`, kết quả thu được tương ứng là `2 * 2 * 3 * 5`.

## Sample 2

### Input
```text
17
```
### Output
```text
17
```
