# Ký Tự Đầu & Ký Tự Cuối


## Nhiệm vụ

Nhập vào một chuỗi ký tự $S$ không chứa dấu cách. Hãy in ra ký tự đầu tiên và ký tự cuối cùng của chuỗi $S$, cách nhau bởi một dấu cách.
## Input

Một chuỗi ký tự $S$ ($1 \le |S| \le 100$).
## Output

Ký tự đầu và ký tự cuối.
## Sample 1

### Input
```text
PYTHON
```
### Output
```text
P N
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
