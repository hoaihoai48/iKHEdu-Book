# Kiểm Tra Số Nguyên Tố


*(Bài toán nền tảng thi Tin học trẻ)*

## Nhiệm vụ

Nhập vào số nguyên $N$. Hãy kiểm tra xem $N$ có phải là số nguyên tố hay không. Nếu có in `YES`, nếu không in `NO`.
## Input

Một số nguyên $N$ ($0 \le N \le 10^7$).
## Output

`YES` hoặc `NO`.
## Sample 1

### Input
```text
7
```
### Output
```text
YES
```
## Sample 2

### Input
```text
1
```
### Output
```text
NO
```
## Sample 3

### Input
```text
9
```
### Output
```text
NO
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
