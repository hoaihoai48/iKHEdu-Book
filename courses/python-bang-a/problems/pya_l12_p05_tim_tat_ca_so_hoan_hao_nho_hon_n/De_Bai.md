# Tìm tất cả số hoàn hảo nhỏ hơn N


## Bối cảnh

Thí sinh đang tìm kiếm một giá trị đặc biệt trong tập dữ liệu. Hãy viết chương trình tìm kiếm hiệu quả.

## Nhiệm vụ

Cho số nguyên dương $N$ ($1 \le N \le 10^4$). Hãy in ra tất cả các số hoàn hảo nhỏ hơn hoặc bằng $N$ theo thứ tự tăng dần.
## Input

Một số nguyên $N$.
## Output

Các số hoàn hảo, cách nhau bởi khoảng trắng.
## Sample 1

### Input
```text
30
```
### Output
```text
6 28
```
### Giải thích

Với dữ liệu đầu vào là `30`, kết quả thu được tương ứng là `6 28`.
