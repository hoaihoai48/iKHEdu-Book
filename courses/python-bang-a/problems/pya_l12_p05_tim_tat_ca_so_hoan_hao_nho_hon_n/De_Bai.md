# Tìm Tất Cả Số Hoàn Hảo Nhỏ Hơn N


## Nhiệm vụ

Cho số nguyên dương $N$ ($1 \le N \le 10^4$). Hãy in ra tất cả các số hoàn hảo nhỏ hơn hoặc bằng $N$ theo thứ tự tăng dần.
## Input

Một số nguyên $N$.
## Output

Các số hoàn hảo, cách nhau bởi khoảng trắng.
## Sample 1

### Input
```text
30
```
### Output
```text
6 28
```


## Ràng buộc


* **Giới hạn thời gian:** $1.0\text{s}$
* **Giới hạn bộ nhớ:** $256\text{MB}$
